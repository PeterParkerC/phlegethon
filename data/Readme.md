# JINA REACLIB Reaction Rates 

The rates stored in this repository (`jina_reaclib_2026-09-06`) originate from the **JINA REACLIB Database**, maintained by the Joint Institute for Nuclear Astrophysics (JINA) and hosted at  https://reaclib.jinaweb.org/

This repository uses the **JINA REACLIB `default` library snapshot dated 2026-06-09**.

We acknowledge the **JINA Reaclib Database** and the JINA nuclear-astrophysics community for compiling, evaluating, fitting, and maintaining the nuclear reaction-rate data used by this repository.
